# The Datum — Fallcall song select

**Feel.** Overcast concrete, not a dark UI. The world is pale sky, grey low-poly planes, vast
and slow — so song select is that space standing still. The screen is light because every
client in this genre is dark, and because the space you fall through is bright. Structure is
flat planes and hard edges; the only shadow is a hard offset. Two background planes drift 2%
over 96 seconds. Nothing else moves.

**The one idea.** *The selection is a fixed line.* The library scrolls through it; the selected
band never moves. Intent #1 needs a stable target, not a fast list — the returning player's map
is restored exactly where it always sits, and Enter plays it. That is also why the default sort
is title, not recently-played: recency reorders the library every session and destroys the
spatial memory intent #1 is made of. Recency stays available in sort; it is not the default.

**Deviation, declared.** The brief says text sits on top of arbitrary user images and asks me to
solve it. **I refused the premise.** Text never touches artwork. The cover is quarantined in a
hard-framed 132px square; type sits on opaque plate. Nothing outside the square changes when the
cover changes, so no cover can break the card — the proof frame shows blinding-white, black-void,
text-covered and full-spectrum covers producing four identical layouts. What I bought: escape
from the scrim-over-art bet, which every client here makes and which fails on precisely the
covers players own. What I paid: the art is smaller and the screen is less of a poster.

**Colour still comes from content.** The cover is sampled, then clamped to L 42–62% / S ≤ 38%,
and only ever feeds the 8px spine and the far background wash. The screen recolours per map but
can never gain or lose contrast from one. Nothing structural depends on hue, so a player
recolouring the accent changes a spine and a wash — not the design.

**Hierarchy.** Title, then star. The star holds one x across every row, every band, every
difficulty, so the library is a single vertical scan. Star colour is a brightness ramp and the
number is always present. CS/AR/OD/HP appear only on the difficulty already chosen for reading.

**Cut:** hover-preview chrome (the behaviour stays, the UI for it doesn't), rank/leaderboard
panel, mods, per-map stats, a second sidebar, and dark mode. Online is a toggle, not a page.

**Assumed, not asked:** 1080p-and-up widescreen; the right third stays air on purpose.
